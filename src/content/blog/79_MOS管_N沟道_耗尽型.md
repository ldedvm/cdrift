## 学习目标
- 理解耗尽型与增强型的本质区别

## 核心概念
- 耗尽型:出厂自带沟道,V_GS = 0 时就已经导通
- 控制:加负压 V_GS < 0 来"夹断"电流(V_GS(off) 为夹断电压)——与增强型"加正压才开"正好相反
- N 沟道耗尽型:V_GS = 0 导通,负压关断;常用于恒流源、高压启动电路
- 应用较少,认识即可;常见型号如 DN2540(高压耗尽型)
- 记忆:增强型"常闭阀",耗尽型"常开阀"
