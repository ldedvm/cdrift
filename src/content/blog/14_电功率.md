## 学习目标
- 掌握电功率的定义和 P = UI 及其变形
- 会用额定功率/额定电压判断元件是否安全

## 核心概念
- 电功率:单位时间消耗的电能,P = UI = I²R = U² / R(三个式子按已知量选用)
- 单位:瓦特(W);常用 mW、kW,1 kW = 1000 W
- 电能 W = Pt,生活中"1 度电" = 1 kW·h = 1000 W 工作 1 小时
- 元器件都有额定功率(如电阻 0.25 W),实际功率超过就会过热烧毁
- 串联电路选 P = I²R,并联电路选 P = U² / R 更方便

## 易错点
- P = I²R 和 P = U² / R 看似矛盾(一个"R 越大功率越大",一个相反),其实取决于哪个量不变——串联电流同、并联电压同
