## 学习目标
- 总结 ORM 模块的核心知识点
- 串联建表、查询、新增、更新、删除流程
- 为后续做完整 FastAPI 项目做准备

## 一条完整链路
1. 安装依赖，创建数据库连接
2. 定义 ORM 模型类
3. 创建数据表
4. 编写 `get_db()` 依赖
5. 在路由中接入数据库会话
6. 实现查询、分页、统计
7. 实现新增、更新、删除
8. 配合 Pydantic 做输入输出校验

## 课程案例回顾
- 用户表模型：`User`
- 数据库会话：`SessionLocal`
- 依赖注入：`get_db()`
- 列表接口：分页 + 搜索 + 筛选
- 详情接口：按主键查询
- 新增接口：校验 + 写入 + 刷新
- 更新接口：部分字段更新
- 删除接口：存在性校验 + 提交事务

## 完整项目结构建议
```text
project/
├─ main.py
├─ database.py
├─ models.py
├─ schemas.py
├─ crud.py
└─ routers/
   └─ users.py
```

## 现阶段你应该掌握什么
- 能读懂并写出基础 FastAPI 路由
- 能定义请求体和响应模型
- 能使用 SQLAlchemy 2.0 建表
- 能完成用户表的增删改查
- 能写出分页、模糊搜索和统计接口

## 下一步建议
- 学 Alembic，解决表结构迁移问题
- 学 MySQL 或 PostgreSQL，替换 SQLite
- 学认证与权限，例如 JWT
- 学异步数据库、项目分层、测试和部署

## 我的补充
- 到这里，你已经不只是“会写几个接口”，而是具备了做一个小型 FastAPI 后端项目的骨架能力。
- 真正要继续提高，接下来就是把这些知识拆到更规范的目录结构里，并逐步加入鉴权、日志、部署、测试。
- 现在最适合你的动作不是继续看更多概念，而是把 `案例代码/main.py` 跑起来，然后边改边学。
